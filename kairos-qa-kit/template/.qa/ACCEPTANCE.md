# Global Acceptance Criteria

Эти критерии действуют для всех задач проекта, если в `CURRENT_TASK.md` не указано иначе.

## Обязательные

- [ ] Проект запускается в заявленной среде.
- [ ] Сборка завершается без ошибок.
- [ ] Линтер и typecheck проходят, когда они существуют в проекте.
- [ ] Автоматические тесты проходят, когда они существуют.
- [ ] Основной пользовательский сценарий выполнен полностью.
- [ ] Ошибочный ввод обрабатывается понятно и безопасно.
- [ ] Данные сохраняются и отображаются корректно.
- [ ] После обновления страницы состояние соответствует требованиям.
- [ ] В браузерной консоли нет новых критических ошибок.
- [ ] Нет новых неуспешных сетевых запросов в основном сценарии.
- [ ] Мобильная версия не ломает основные действия.
- [ ] Не добавлены секреты, пароли или ключи в репозиторий.
- [ ] Нет открытых P0/P1/P2.
- [ ] `.qa/QA_REPORT.md` содержит `QA_VERDICT: PASS`.
- [ ] `.qa/RELEASE_REPORT.md` содержит `RELEASE_VERDICT: PASS`.

## Не блокирует выпуск автоматически

- небольшая косметика;
- необязательная микровзаимодействие;
- вкусовые предложения;
- рефакторинг без доказанной проблемы;
- функции вне scope.
