# Як тестувати: запрошувальні посилання (Тип 2, посіви)

Пошаговая інструкція для ручного тесту. Ці кроки вимагають реального Telegram-бота
й каналу, тому їх не можна перевірити автоматично — пройди по пунктах і познач ✅/❌.

## Що знадобиться

- [ ] Доступ у кабінет ClearTG, канал з підключеним ботом (адмін з правом «Додавання учасників»).
- [ ] Кампанія з джерелом, відмінним від Meta/Google/TikTok (наприклад «Інфлюенсер» чи «Органіка») —
      або створи нову на сторінці «Кампанії».
- [ ] Другий Telegram-акаунт, ще не підписаний на тестовий канал.

---

### 1. Створення посилання
1. `/links` → блок «Запрошувальні посилання (посіви)» → вкажи назву джерела, канал, кампанію.
2. Натисни «Створити».

**Очікуємо:** посилання виду `t.me/+код` з'явилось у списку зі статусом «Активне».
- [ ] ОК / ❌ не ок

### 2. Блокування для платної реклами
1. Спробуй вибрати кампанію з джерелом Meta/Google/TikTok у цій самій формі.

**Очікуємо:** такої кампанії немає у списку (форма заздалегідь показує тільки придатні),
або, якщо створити напряму через API, повертається зрозуміла помилка — не тиха відмова.
- [ ] ОК / ❌ не ок

### 3. Підписка по посиланню — джерело видно точно
1. Скопіюй посилання, відкрий його з другого акаунта, підпишись на канал.
2. У кабінеті: «Підписники» → знайди щойно доданого підписника.

**Очікуємо:** джерело — назва кампанії/посилання, а не «Джерело невідоме»; при наведенні на
рівень точності — «100%» / exact, а не «ймовірне».
- [ ] ОК / ❌ не ок

### 4. Два джерела на один канал не плутаються
1. Створи друге запрошувальне посилання під іншу кампанію.
2. Підпишись по ньому з третього акаунта.
3. Перевір «Підписники» — обидва підписники мають свої, різні джерела.
- [ ] ОК / ❌ не ок

### 5. Ручне відкликання в кабінеті
1. На `/links` натисни «Відкликати» біля посилання зі статусу «Активне».
2. Спробуй ще раз відкрити те саме посилання (з нового акаунта, що ще не підписаний).

**Очікуємо:** статус змінився на «Відкликане», а Telegram більше не пускає по цьому посиланню
(Telegram сам покаже, що воно недійсне). Статистика (кількість підписок) біля посилання лишилась.
- [ ] ОК / ❌ не ок

### 6. Видалення вручну в Telegram — система це помічає
1. Створи нове запрошувальне посилання.
2. У самому Telegram (не в кабінеті!): налаштування каналу → посилання-запрошення → видали/відклич
   саме це посилання.
3. Почекай до ~1 години (планова перевірка щогодини на :30) або попроси розробника запустити
   перевірку вручну.
4. Перевір `/links` і Telegram кабінету-бота.

**Очікуємо:** посилання позначено «Відкликане», у бот кабінету прийшло попередження з назвою
посилання й каналу, накопичена раніше статистика лишилась на місці.
- [ ] ОК / ❌ не ок

### 7. Чесність інтерфейсу щодо обмежень
1. Прочитай пояснення під формою створення запрошувального посилання.

**Очікуємо:** прямо написано, що немає конкретного поста і немає UTM-міток, і чому (Telegram
відкриває канал цілком, обійти не можна) — без окремих полів, які тихо ігноруються.
- [ ] ОК / ❌ не ок
