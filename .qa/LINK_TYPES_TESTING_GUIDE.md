# Как тестировать: 4 типа посилань

Пошаговая инструкция для ручного теста. Ничего технического знать не нужно — просто выполняй шаги по порядку и отмечай ✅/❌. Каждый пункт независим, можно тестировать не по порядку.

**Как читать шаги «в лівому меню»:** в кабинете слева — вертикальное меню. Везде ниже, где написано «зайди в X», имеется в виду: кликнуть по названию X в этом левом меню. Названия пунктов меню (сверху вниз): Огляд, Канали, Учасники, Кампанії, **Посилання**, Lead Magnets, Звіти, Джерела (CR), Підписки, Переходи в бота, Meta, Google Ads, GA4, TikTok, Свій бот, Команда, Telegram-бот, Приватність, Аудит.

Для более глубокой проверки типа 2 (пригласительная) и типа 4 (бот) есть отдельные гайды: `.qa/SEED_INVITE_LINKS_TESTING_GUIDE.md` и `.qa/BOT_LINKS_TESTING_GUIDE.md`. Здесь — базовая проверка всех четырёх типов и сквозные пункты.

## Что понадобится перед началом

- [ ] Доступ в кабинет ClearTG (обычный логин).
- [ ] Тестовый Telegram-канал, бот добавлен админом с правом **«Додавання учасників»**. Проверить это можно в меню **Канали** — у канала должен быть зелёный бейдж «Бот адмін» (если жёлтый «Потрібні права» — права не те, что нужны).
- [ ] Пост в этом канале с известным номером — открой пост в самом Telegram, скопируй на него ссылку («Копіювати посилання» в меню поста), номер — последнее число в скопированной ссылке (`t.me/канал/42` → номер 42).
- [ ] **Второй Telegram-аккаунт** (не тот, что в кабинете) и по возможности **третий** — для п.3.
- [ ] Доступ к настройкам самого канала в Telegram (убрать бота, удалить посилання вручную — это часть теста).
- [ ] Кампания в кабинете с источником НЕ Meta/Google/TikTok — нужна для пригласительной ссылки. Как создать — см. ниже.

### Подготовка: создать тестовую кампанию (если ещё нет)

1. В левом меню зайди в **Кампанії**.
2. В форме «Нова кампанія» заполни:
   - **Назва** — например `QA посів`.
   - **Платформа / джерело** — выбери из списка **«Інфлюенсер / посів»** (или «Органіка / пряме посилання» — главное НЕ Meta/Google/TikTok, под полем есть подсказка почему).
   - **Канал** — твой тестовый канал.
3. Нажми **«Створити кампанію»**.

Эта кампания понадобится в пунктах 2 и 3 ниже — при создании пригласительной ссылки в выпадающем списке «Кампанія» будут показаны только подходящие (не paid) кампании.

## Каждый тип по отдельности

### 1. Создали ссылку каждого из четырёх типов

**Тип 1 — обычная.** Просто открой `t.me/назва_каналу` (нужен публичный `@username` канала) — либо просто держи в уме, что для приватного канала обычная ссылка вообще недоступна.

**Тип 2 — пригласительная:**
1. Зайди в **Посилання**.
2. Прокрути страницу вниз до блока **«Запрошувальні посилання (посіви)»**.
3. В форме под ним заполни:
   - **Назва джерела** — например `QA тест 1`.
   - **Канал** — тестовый канал.
   - **Кампанія** — та, что создали в разделе «Підготовка» выше (если поле показывает жёлтое предупреждение «Немає кампаній, придатних для посіву» — значит кампания ещё не создана).
4. Нажми **«Створити запрошувальне посилання»**.
5. Новая строка появится в списке ниже формы — ссылка вида `t.me/+код` показана моноширинным шрифтом, выдели и скопируй её текст.

**Тип 3 — трекинговая:**
1. На той же странице **Посилання** — форма **«Нове tracking-посилання»** (она выше блока с пригласительными).
2. Заполни: **Назва** (любая), **Тип** оставь «Landing /l/…», **Куди веде посилання** — оставь «Канал (за замовчуванням)», **Джерело реклами** — любое, **Канал** — тестовый канал.
3. Нажми **«Створити посилання»** — тебя перекинет обратно на `/links`, новая ссылка (вида `https://…/l/код`) появится первой в списке над блоком пригласительных.

**Тип 4 — через бота:**
1. Перед этим на боте должен быть подключён «Свій бот» — если нет, зайди в **Свій бот** в меню и подключи тестового бота через токен от @BotFather.
2. Вернись в **Посилання** → форма «Нове tracking-посилання» → в поле **«Куди веде посилання»** выбери **«Свій бот (переходи в бота, /start з міткою)»** → появится выбор конкретного бота → заполни остальное как обычно → **«Створити посилання»**.

Теперь открой все четыре по очереди (обычную — если у канала есть username, иначе пропусти эту часть пункта).

**Ожидаем:** все они открываются и приводят в нужный канал (последняя — в чат с ботом).
- [ ] ОК / ❌ не ок

### 2. Пригласительная: подписались — источник виден

1. Возьми ссылку типа 2 из п.1.
2. Открой её **со второго аккаунта** (не с того, что в кабинете), нажми «Приєднатися»/«Join».
3. В кабинете зайди в **Учасники**.

**Ожидаем:** в таблице новая строка с этим аккаунтом, в колонке **«Джерело»** — название твоей кампании (`QA посів` или как назвал), а НЕ пустое поле и не «Джерело невідоме». Для более точной проверки — кликни по нику подписчика (откроется «Досьє підписника»), в блоке **«Джерело та атрибуція»** поле **«Впевненість»** должно показывать **100%**.
- [ ] ОК / ❌ не ок

---

### 3. Две пригласительные под разные источники — не перепутались

1. Создай вторую кампанию (как в разделе «Підготовка», другое название) и вторую пригласительную ссылку под неё (как в п.1, тип 2).
2. Подпишись по первой ссылке с одного аккаунта, по второй — с другого (третьего).
3. Зайди в **Учасники**.

**Ожидаем:** у каждого из двух — своя, правильная кампания в колонке «Джерело», ничего не перепутано.
- [ ] ОК / ❌ не ок / пропущено (нет третьего аккаунта)

---

### 4. Трекинговая с указанием поста

1. Зайди в **Посилання** → форма «Нове tracking-посилання».
2. В поле **«Куди веде посилання»** оставь «Канал», под ним появится чекбокс **«Вести на конкретний пост, а не на канал цілком»** — включи его.
3. Появится поле — впиши номер поста, который посмотрел заранее (см. «Что понадобится»).
4. **«Створити посилання»**, открой созданную ссылку (первая в списке, `/l/код`).

**Ожидаем:** канал открылся на нужном посте, а не на последнем/первом. Если у канала нет публичного `@username` — откроется канал целиком (это ожидаемо, под чекбоксом об этом прямо написано).
- [ ] ОК / ❌ не ок

---

### 5. Трекинговая: время до переброса

1. Открой любую tracking-посилання из предыдущих пунктов.
2. На глаз/секундомером оцени, сколько времени висит наш адрес перед тем, как откроется Telegram.

**Ожидаем:** незаметно, доли секунды. Если видна задержка или мелькает страница — это брак, зафиксируй.
- [ ] ОК / ❌ не ок

---

### 6. Ссылка через бота

1. Возьми ссылку типа 4 из п.1.
2. Открой её **внутри Telegram** (не в обычном браузере) со второго аккаунта — она должна открыть чат с ботом.
3. Нажми **«Start»** внизу чата.
4. В кабинете зайди в **Переходи в бота**.

**Ожидаем:** переход прошёл без выхода из приложения; в таблице (колонки Дата/Бот/Користувач/Статус/Посилання/UTM) появилась новая строка.
- [ ] ОК / ❌ не ок

## Границы и отказы

### 7. Разные платформы

Открой одну и ту же tracking-посилання (например из п.5) на:
- [ ] iPhone — переброс сработал
- [ ] Android — переброс сработал
- [ ] десктопное приложение Telegram — переброс сработал
- [ ] веб-версия Telegram (web.telegram.org) — переброс сработал

Отдельно запиши, на каких платформах выскакивает системное окно подтверждения («Открыть в Telegram?») — это влияет на конверсию, клиента нужно предупредить.

---

### 8. Браузер без Telegram

1. Открой ту же трекинговую ссылку в браузере на компьютере, где Telegram не установлен (или в режиме «инкогнито» без ассоциации ссылок).

**Ожидаем:** человек попал на веб-версию Telegram (web.telegram.org), а не в ошибку браузера/пустую страницу.
- [ ] ОК / ❌ не ок

---

### 9. Ссылка на несуществующий пост

1. Как в п.4, создай tracking-посилання с конкретным постом, но впиши заведомо несуществующий номер (например `999999`).
2. Открой её.

**Ожидаем:** человек попал в канал, а не на пустой экран или ошибку Telegram.
- [ ] ОК / ❌ не ок

---

### 10. Ссылка на канал, из которого убрали бота

1. В Telegram открой настройки тестового канала → Администратори → найди нашего бота → убери его из админов (или сними все права, особенно «Додавання учасників»).
2. Подожди 10–20 секунд.
3. Зайди в кабинете в **Канали** — у канала бейдж должен стать жёлтым «Потрібні права» (это подтверждает, что кабинет узнал об изменении).
4. Открой любую активную tracking-посилання этого канала (например из п.5).
5. Верни боту права обратно (обязательно «Додавання учасників»), подожди 10–20 секунд, убедись, что бейдж в **Канали** снова зелёный «Бот адмін».
6. Открой ту же ссылку ещё раз.

**Ожидаем:** после шага 4 — страница с текстом вида «{Назва каналу} тимчасово недоступний» и понятным объяснением, а НЕ пустой экран, не редирект в никуда, не ошибка браузера. После шага 6 (права возвращены) — та же ссылка снова открывает канал нормально.
- [ ] ОК / ❌ не ок

---

### 11. Удалили пригласительную ссылку в самом Telegram

1. Создай новую пригласительную ссылку (тип 2, как в п.1).
2. В самом Telegram (не в кабинете!) — настройки канала → «Посилання-запрошення» (или «Invite Links») → найди это посилання в списке → «Відкликати посилання» / удали вручную.
3. Подожди до ~1 часа (в кабинете раз в час идёт плановая проверка) — или попроси разработчика запустить проверку вручную, чтобы не ждать.
4. Обнови страницу **Посилання**, найди это посилання в блоке «Запрошувальні посилання».

**Ожидаем:** статус посилання сменился на **«Відкликане»** (красный бейдж); в Telegram-боте кабинета (тот, к которому привязан твой аккаунт) пришло сообщение с предупреждением, где указаны название посилання и канала; счётчик «N підписок» у этого посилання остался прежним, не обнулился.
- [ ] ОК / ❌ не ок

---

### 12. Двадцать кликов с одного устройства

1. Открой одну и ту же tracking-посилання двадцать раз подряд с одного устройства (можно просто много раз нажать «Назад»/открыть заново).
2. Зайди в **Джерела (CR)**.
3. Найди эту ссылку в таблице «Tracking-посилання».

**Ожидаем:** в колонке «Кліки» — число 20 (или сколько раз реально открыл), а под ним мелким серым текстом — `≈1 відвідувачів`. Это значит: клики посчитаны честно, но отчёт понимает, что это один человек.
- [ ] ОК / ❌ не ок

## Проверка ограничений, которые мы обещали

### 13. Пригласительная с указанием поста

1. Зайди в **Посилання** → прокрути до формы «Нове запрошувальне посилання (посів)».

**Ожидаем:** в форме физически нет поля для номера поста — только Назва джерела / Канал / Кампанія. В тексте над полями прямо написано, почему конкретного поста нет (Telegram не вміє поєднати інвайт і конкретний пост). Форма не должна тихо принимать номер поста и потом его игнорировать — раз поля нет, значит и обманывать нечем.
- [ ] ОК / ❌ не ок

---

### 14. UTM-метки к пригласительной

1. Та же форма запрошувального посилання.

**Ожидаем:** нет полей для UTM source/medium/campaign, и в тексте написано, что их не будет и почему (нет UTM у самого посилання). Понятный отказ, а не тихая потеря данных.
- [ ] ОК / ❌ не ок

---

### 15. У каждого типа написано, что он умеет

1. Зайди в **Посилання** — прямо под заголовком страницы таблица **«4 типи посилань — що обрати»** (4 строки: колонки Тип / Точність джерела / Вміє / Не вміє).
2. Дополнительно проверь пояснения возле самих полей: чекбокс «Вести на конкретний пост» (текст под ним появляется, если включить), выбор «Свій бот» и «Особистий акаунт» в «Куди веде посилання» (текст появляется под выбором).

**Ожидаем:** по каждому из 4 типов клиент видит, что тип умеет и чего не умеет, ещё до создания рекламы — не должно быть сюрпризов после её запуска.
- [ ] ОК / ❌ не ок

## Сверка между собой

### 16. Сто человек через разные ссылки на один канал

Полноценно нужно 100 реальных вступлений — минимальная версия:
1. Возьми по одной ссылке каждого типа на один и тот же канал (из пунктов 1–4).
2. Подпишись по каждой с разных тестовых аккаунтов — 3–5 штук достаточно, чтобы проверить, что цифры не путаются.
3. Зайди в **Джерела (CR)** и в **Учасники**.

**Ожидаем:** в общем отчёте ссылки не смешались — у каждой своя, отдельная цифра подписок, в «Учасники» у каждого человека свой правильный источник.
- [ ] ОК / ❌ не ок / частично (указать сколько аккаунтов реально протестировано)

---

### 17. Сумма сходится с реальным приростом канала

Это главная проверка: если не сходится — где-то теряем людей.

1. Перед тестом открой сам канал в Telegram → «Учасники»/«Подписчики» → запиши точное число.
2. В течение дня проведи несколько подписок по разным ссылкам и напрямую (без ссылки вообще).
3. В конце дня зайди в **Огляд** (главная страница кабинета).
4. Посмотри на карточку **«Атрибуція»** — сложи цифры по всем строкам (там же есть «Органіка»/«Невідомо» — это и есть «джерело невідоме»).

**Ожидаем:** сумма из карточки «Атрибуція» совпадает с реальным приростом канала за день (число подписчиков в Telegram выросло на столько же). Дополнительно: на **Огляд** не должно быть красного баннера **«Технічна нестиковка»** вверху страницы — если он появился, суммы гарантированно не сойдутся, скриншот и сразу разработчику, разбираться руками не нужно.
- [ ] ОК / ❌ не ок

## Если что-то пошло не так

Для каждого ❌ зафиксируй:
1. Номер пункта.
2. Что делал (точные шаги).
3. Что ожидал / что увидел на самом деле.
4. Скриншот, если возможно.

Передай это разработчику — этого достаточно, чтобы воспроизвести проблему.
