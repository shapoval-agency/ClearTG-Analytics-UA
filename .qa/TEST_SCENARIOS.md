# Test Scenarios

Добавляйте постоянные сценарии проекта. Один сценарий — один проверяемый результат.

## TS-001 — Клік по рекламі → атрибутована підписка

- Priority: P1
- Preconditions: є активний tracking-посилання (`/l/:slug`) з `destinationMode=INVITE_LINK`, бот доданий адміном каналу з правом «Додавання учасників»
- Test data: тестовий Telegram-акаунт без активної підписки на канал
- Steps:
  1. Відкрити `/l/:slug` — має статися редирект (302) на персональне invite-посилання Telegram.
  2. Приєднатися до каналу за цим посиланням.
  3. Відкрити кабінет → Підписники / бот → «Останні підписники».
- Expected: новий підписник з'являється з `attributionType = EXACT_CLICK_INVITE`, вірним джерелом (UTM) і часом по Києву.
- Evidence: рядок у `/api/dashboard/subscribers`, запис `Attribution` у БД.

## TS-002 — Швидкий цикл підписка→відписка→підписка

- Priority: P0
- Preconditions: тестовий канал з ботом-адміном
- Test data: один Telegram-акаунт
- Steps:
  1. Підписатися на канал.
  2. Відписатися.
  3. Повторити підписку/відписку ще 2 рази поспіль (у межах кількох хвилин).
- Expected: у «Останні підписники» — 3 окремих профілі підписки для цього користувача, кожен цикл зафіксовано окремо (жоден цикл не «зникає»).
- Evidence: `SubscriberProfile` rows + `UnsubscribeEvent` rows для `telegramUserId`, кожен профіль або активний, або має свою відписку.

## TS-003 — Щоденний дайджест у Telegram-боті

- Priority: P1
- Preconditions: минула доба з реальною активністю (підписки/відписки) хоча б в одному каналі workspace
- Test data: workspace з ≥1 каналом, що мав активність за «вчора»
- Steps:
  1. У боті натиснути «📊 Звіт за вчора» (або дочекатись ранкової розсилки).
  2. Переглянути отримані повідомлення.
- Expected: окреме повідомлення на кожен канал з активністю (канали без активності — без повідомлення), підписники/відписки згруповані по джерелу, час — за Києвом.
- Evidence: скріншот повідомлень бота.

## TS-004 — Підключення каналу сповіщає весь workspace

- Priority: P1
- Preconditions: у workspace ≥2 учасники з привʼязаним Telegram
- Test data: тестовий канал, ще не підключений
- Steps:
  1. Учасник A (не власник) додає бота адміном у новий канал.
  2. Перевірити Telegram будь-якого іншого привʼязаного учасника workspace.
- Expected: повідомлення «✅ Канал підключено» приходить УСІМ привʼязаним учасникам workspace, а не лише тому, хто додав бота.
- Evidence: скріншот повідомлення в Telegram кожного учасника.
