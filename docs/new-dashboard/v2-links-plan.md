## 2. Главное ограничение: тип ссылки не выбирается свободно

Это определяет всю конструкцию раздела.

### Правило платформы → режим ссылки

[link-mode.ts](../../packages/shared/src/link-mode.ts) + [tracking.service.ts:71](../../apps/api/src/tracking/tracking.service.ts#L71):

| Платформа кампании | `SHORTLINK` (`/r/`) | `LANDING_PAGE` (`/l/`) | Значение по умолчанию |
|---|---|---|---|
| META, GOOGLE, TIKTOK | ❌ запрещён | ✅ | `LANDING_PAGE` |
| INFLUENCER, ORGANIC, TELEGRAM_ADS, DIRECT, OTHER | ✅ | ✅ | `SHORTLINK` |
| кампания не указана | ✅ | ✅ | `LANDING_PAGE` |

Попытка создать `SHORTLINK` для платной платформы вернёт 400: «SHORTLINK заборонений для paid traffic (Meta, Google, TikTok)».

### Правило для запрошувальных ссылок

[invite-link.service.ts:105](../../apps/api/src/telegram/invite-link.service.ts#L105) отклоняет создание инвайта, если кампания на платной платформе:

> «Запрошувальні посилання не призначені для платної реклами (Meta/Google/TikTok) — там немає UTM-міток і немає прив'язки клік→підписка».

### Следствие для интерфейса

**Пользователь не должен выбирать `LinkMode`** — он не знает, что такое `/l/` и `/r/`, и не обязан помнить правила модерации.

Правильный вопрос: **«звідки піде трафік?»**. Тип ссылки выводится из ответа, недопустимые варианты просто не показываются.

```
Канал → Джерело трафіку → доступні типи посилань → мітки → готове посилання
```

## 3. Второе ограничение: запрошувальна ссылка требует кампанию

`POST /api/invite-links` требует `campaignId` **обязательно** (не `@IsOptional`). У трекинговой ссылки кампания опциональна, но именно она определяет режим.

При этом по [DEC-005](./DECISIONS.md) кампании — не раздел меню, а свойство ссылки.

**Решение:** в конструкторе поле «Джерело трафіку» — это выбор кампании из существующих, плюс возможность создать новую тут же через `POST /api/campaigns`.

Без этого пользователь без кампаний вообще не сможет создать запрошувальну ссылку — а это ровно сценарий посева, ради которого раздел и нужен.

> Создание кампании внутри конструктора — не новая функция: используется существующий эндпоинт. Отдельного раздела «Кампанії» по-прежнему нет.

## 4. Три типа ссылок в MVP

| Тип | Что это | Как создаётся | Точность источника |
|---|---|---|---|
| **Трекінгове посилання** | `/l/{slug}` или `/r/{slug}` — фиксирует клик, метки и ведёт в Telegram | `POST /api/tracking-links` | Точная: клик → invite → подписка |
| **Запрошувальне під джерело** | `t.me/+код` — Telegram сам сообщает, какой инвайт использован | `POST /api/invite-links` | Точная, но без UTM и без клика |
| **Звичайне t.me** | Обычная ссылка на канал | **Ничего не создаётся** | Нет: подписка уйдёт в «джерело не визначене» |

Третий тип — не сущность в базе, а честное объяснение. В конструкторе он показывает готовую `t.me/username` и прямо предупреждает, что источник таких подписок определить нельзя. Это и есть задача S1-06: поддержать сценарий, но не врать о нём.

> Для приватного канала без `username` обычной ссылки не существует — вариант должен быть недоступен с объяснением.

## 7. Состояния UI

| Состояние | Когда | Что показываем |
|---|---|---|
| **Loading** | Загрузка | `loading.tsx` |
| **Empty** | Ссылок нет | Объяснение зачем нужны ссылки + конструктор сразу раскрыт |
| **Error** | API недоступен | «Сервіс аналітики зараз не відповідає» — без технического текста |
| **Success** | Ссылки есть | Список + свёрнутый конструктор |
| **Disconnected** | Каналов нет вообще | «Спочатку підключіть канал» + ссылка на `/v2/channels` |

Отдельные состояния конструктора: ошибка Telegram при создании инвайта (бот потерял права), ошибка правил платформы (400 от бэкенда), успех с готовой ссылкой и кнопкой копирования.

## 8. Пользовательский сценарий

```
Кабінет → Посилання
   │
   ├─ каналів немає
   │     «Спочатку підключіть канал» → /v2/channels
   │
   ├─ посилань немає
   │     Конструктор розгорнутий одразу
   │
   └─ посилання є
         ┌────────────────────────────────────────────────────────┐
         │ Літня кампанія            Трекінгове    ● Активне      │
         │ tets · Meta · utm: meta · креатив: video_1             │
         │ cleartg.app/l/ih42v5f          37 кліків               │
         │                        [Копіювати] [Архівувати]        │
         ├────────────────────────────────────────────────────────┤
         │ Посів: канал Х            Запрошувальне ● Активне      │
         │ tets · Influencer                                      │
         │ t.me/+AbCdEf                                           │
         │                        [Копіювати] [Відкликати]        │
         └────────────────────────────────────────────────────────┘

  Конструктор:
    1. Канал            [tets ▾]
    2. Джерело трафіку  [Meta paid campaign ▾]  або «+ Нове джерело»
    3. Тип посилання    ○ Трекінгове  ○ Запрошувальне  ○ Звичайне t.me
                        ↑ недоступні варіанти приховані з поясненням
    4. Мітки            назва · UTM · креатив · пост (згорнуто)
    5. [Створити]  →  готове посилання + [Копіювати]
```

Раздел отвечает на вопрос: **под какой источник эта ссылка и работает ли она.**

## 10. Границы задачи

**Делаем:** список обоих типов ссылок с фильтрами, конструктор с выводом типа из источника, UTM и метка креатива, копирование ссылки, архивация трекинговых, отзыв инвайтов, создание источника внутри конструктора, пять состояний UI.

**Не делаем:** редактирование ссылки (S2-07, этап 2), клонирование (S2-06), массовое создание (S2-09), удаление, QR-коды, встраиваемый скрипт и `GET :slug/embed`, переход в бота и в личку (S2-03, S2-05), advanced-поля старой формы.

**Не трогаем:** `apps/api`, `packages/*`, схему БД, маршруты `/l/:slug` и `/r/:slug`, старый кабинет.

## 11. Открытый вопрос

`GET /api/tracking-links` и `GET /api/invite-links` возвращают **все** записи workspace без пагинации и фильтра по каналу. Сейчас их 5 — проблемы нет. При сотнях ссылок список станет тяжёлым, а фильтрация ляжет на клиент.

Для MVP этого достаточно. Расширение API — этап 2, вместе с фильтром периода для отчётов (S1-21). Зафиксировано, чтобы не решать задним числом.
